# Calculator

A simple Python console calculator that performs arithmetic operations with two numbers.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Division-by-zero protection
- Handling invalid number input

## How to Run

Make sure Python is installed. Open the terminal in the project folder and run:

```bash
python main.py 
```

Follow the prompts in the terminal to enter two numbers and choose an operation.
